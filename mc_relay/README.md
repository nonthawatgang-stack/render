# Monster Crafter — เซิร์ฟเวอร์ต่อห้องเล่นกับเพื่อน

โปรแกรมเล็ก ๆ สำหรับสร้างห้องด้วยรหัส 5 ตัว และส่งข้อมูลระหว่างเครื่องในห้องเดียวกัน (สูงสุด 4 คน) ไม่ได้เก็บเซฟหรือข้อมูลผู้เล่น

## เปิดบน Render (ฟรี)
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub เป็น repo ใหม่
2. ที่ render.com → New → Web Service → เลือก repo นี้
3. Runtime: Node · Build: (เว้นว่าง หรือ `npm install`) · Start: `npm start` · Plan: Free
4. ได้ที่อยู่ เช่น `https://mc-relay.onrender.com` → ในเกม ใส่ `wss://mc-relay.onrender.com` ในช่องเซิร์ฟเวอร์ (หน้าเล่นกับเพื่อน)

แผนฟรีของ Render จะหลับเมื่อไม่มีคนใช้ ~15 นาที คนแรกที่เข้าจะรอปลุกประมาณ 30 วินาที

## ทดลองในเครื่อง
`npm start` แล้วในเกมใส่ `ws://127.0.0.1:8080`
